# 第一人称 POV 提示词写作规范

## 适用场景

当视频需要模拟"角色眼睛看到的世界"时使用（如回忆片段、主观视角、沉浸式叙事）。核心是：**观众看见的就是角色看见的，画面里不应该出现"角色自己"。**

## 一、核心原则

**原则1：不写"我"，写"视野"**

画面里没有"我"这个人，只有"我"看到的东西。

| ❌ 错误写法 | ✅ 正确写法 |
|------------|-----------|
| 我走向沙发 | 视野转向沙发方向（沙发边缘/靠垫入画） |
| 我坐下，视线变低 | 视野降低（膝盖和手入画） |
| 我回头看 | 视野向侧后方扫去 |
| 我看着孩子玩 | 孩子背影在视野前方 |
| 我蹲下来捡铁环 | 视野微蹲（铁环从脚边进入画面中心） |

**原则2：用"→"连接画面变化，不是写动作描述**

"动作描述"是给演员的，"画面变化"是给镜头的。AI需要知道画面里**出现什么、怎么动**，不是"角色在干什么"。

| ❌ 错误写法 | ✅ 正确写法 |
|------------|-----------|
| 我转身走向沙发然后坐下 | 视野从孩子身上移开→转向沙发方向→往前走（视野前推）→视野降低 |
| 我侧头看了一眼身后 | 视野向侧后方扫去（后方画面入画） |
| 我用手摸了摸儿子的头 | 视野里自己的手抬起来（落在儿子头顶） |

**原则3：用"入画/出画/变近/变远/变暗/变亮"描述变化**

第一人称里没有"角色在画面中的位置变化"，只有"画面内容的变化"。

| 动作 | 第一人称写法 |
|------|-------------|
| 靠近某物 | 视野前推（物体变大） |
| 远离某物 | 视野后退（物体变小） |
| 蹲下 | 视野降低（地面入画） |
| 站起来 | 视野抬升（视线从低变高） |
| 闭眼 | 视野从四边收窄变暗→黑场 |
| 睁眼 | 黑场→视野从中心亮起 |
| 回头看 | 视野向侧后方扫去 |
| 低头看 | 视野下移（脚下地面入画） |
| 抬头看 | 视野上移（天空/高处入画） |

## 二、画面描述规范

**规范1：只写画面里"出现"了什么**

用"入画/在视野里/出现在画面边缘"来描述，不用"我看见"。

| ❌ 错误写法 | ✅ 正确写法 |
|------------|-----------|
| 我看见孩子背对着我 | 孩子背影在视野前方 |
| 我看到沙发和靠垫 | 沙发边缘/靠垫入画 |
| 我看见前方有几个男孩 | 前方几个男孩背影在视野里 |
| 我注意到小伙伴在看我 | 一个男孩的脸出现在视野里 |

**规范2：按"时间顺序"排列画面变化**

用"→"按顺序连接，一个箭号等于一个画面变化。

```
视野落在孩子背上→视野移开→转向沙发方向（沙发入画）→视野降低（膝盖入画）→转回孩子方向（他变远了）→视野收窄变暗→黑场
```

**规范3：说话时不写"我说"，写声音入画/出画**

| ❌ 错误写法 | ✅ 正确写法 |
|------------|-----------|
| 我喊"我跑得最快！" | 自己的声音（带得意，喘着气）"我跑得最快！" |
| 我说"肉肉加油" | 自己的声音（温暖，压低）"肉肉加油" |
| 我回答说"没想啥" | 自己的声音（轻）"没想啥。" |

## 三、声音规范

第一人称声音里，自己说话是"近处声音"，别人说话有"远近变化"。

**规范1：远近变化写在声音轨里**

| 声音类型 | 写法 |
|----------|------|
| 自己说话/呼吸 | 近，清晰 |
| 前方的人说话 | 从前方飘过来 |
| 身后的人说话 | 从后方传来 |
| 远处的声音 | 带混响/像隔了一层 |
| 声音在远离 | 渐远/被风扯散/声音变小 |
| 回忆里的声音 | 带混响，像从记忆深处浮上来 |

**规范2：声音轨用"→"连接声音变化**

```
铁环声（近，清晰）→自己奔跑的呼吸声→侧头时铁环声（转向侧方）→铁环声渐远→风声盖过一切→安静→黑场
```

## 四、快速检查清单

写完后检查以下项目：

- [ ] 镜头轨里有没有出现"我"字？（不该有）
- [ ] 画面里有没有出现"角色背影"？（不该有，那属于第三人称跟拍）
- [ ] 每个动作是不是都写了"画面怎么变"而不是"角色怎么做"？
- [ ] 用"→"连接后读一遍，画面变化是不是流畅的？
- [ ] 闭眼/睁眼有没有用"视野收窄变暗/从中心亮起"？
- [ ] 声音轨里标注了远近变化吗？
- [ ] 对话有没有写"谁的声音"而不是"谁说"？

## 五、完整示例（正确版本）

**场景：父亲看儿子玩火车，疲惫闭眼，进入童年回忆。**

```
镜头轨：
视野落在孩子背部和火车轨道上→视野从孩子身上移开→转向沙发方向（沙发边缘/靠垫入画）→往前
走（视野前推）→视野降低（膝盖和手入画）→视野抬起（暖灯在天花板边缘晃了一下）→转回孩子方向（他变远了）→视野从四边开始收窄变暗→黑场

｜画面内：孩子背影（从近变远）/沙发边缘/靠垫/自己膝盖和手/暖灯（天花板边缘）/视野从四边收窄变暗

声音轨：
小火车"咔嗒咔嗒"（近）→孩子"呜呜——火车来咯——"（近）→拖鞋踩木地板声（近）→沙发弹簧"咯吱"一声→呼吸声变缓→小火车声（渐远）→孩子童声（渐远，像隔了一层）→安静→黑场
```

## 六、常见错误速查表

| 错误 | 原因 | 改正 |
|------|------|------|
| 在镜头轨里写"我" | 以为第一人称是在讲"我"的故事 | 用"视野"替代"我" |
| 写"我站起来" | 这是第三人称的动作描述 | 写"视野抬升" |
| 写"我看到孩子" | 第一人称里不需要强调"看到" | 写"孩子背影在视野前方" |
| 写"我回头看了一眼" | 这个动作AI不知道怎么拍 | 写"视野向侧后方扫去" |
| 写"我慢慢闭上眼睛" | 第一人称闭眼画面是暗场 | 写"视野从四边收窄变暗→黑场" |
| 写"他对我说" | 第三人称叙述 | 写"一个男孩的脸出现在视野里（声音传来）" |
| 画面描述里写"我的背影" | 第一人称不该出现自己 | 删掉，那是第三人称跟拍 |
| 声音轨没有远近标注 | AI不知道声音在哪 | 加"近/远/从前方飘来/渐远" |
| 用"看见/听见/注意到" | 这些词带有"主体观察"的意味 | 直接写"入画/出现在视野/声音传来" |
