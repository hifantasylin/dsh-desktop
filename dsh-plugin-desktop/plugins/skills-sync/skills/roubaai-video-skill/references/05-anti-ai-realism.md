# 反 AI 油腻与角色真实感（anti-AI realism）

> 本文件在 05 角色定稿图 / 06 视频 prompt 生成时，若出现以下情况补读：角色"AI 感重 / 太假 / 油腻 / 塑料感 / 完美得不像活人 / 游戏 CG 感 / 壁纸感"，或项目要求真人实景质感。
> 它不替代 05 的 `ST` 风格锁 / `CL` 色彩光影 / `NP` 防跑偏负面词，而是叠加一套"材质真实感"纪律；机制受电影实拍方法论启发，本文全部用 roubaai-video-skill 自己的语言重写，不搬运外部原文。
> 防 AI 感**最有效的一条路是 §7 质感种子图锚定法**：直接文字约束的效果，弱于"先出一张质感对的种子图，再以它为参考图扩四视图/变体"。

---

## 1. 先分档，再应用

| 档位 | 判定 | 应用强度 |
|---|---|---|
| **真人实景档** | 真人电影/短剧/写实都市等，要求像真实摄影机拍的 | 全量应用 + 每批选一个成像基底 |
| **风格化档** | 水彩绘本 / 2D 动画 / 3D / 漫画 / 黏土等非写实 | 只用"反完美 + 信息量克制 + 光有来源"，**不引入**实拍胶片基底/皮肤质感词 |

判定跟随项目 config「动画风格」；无明确风格时按画面主体定，拿不准按真人实景档从严。

## 2. 五条硬规则

### 规则1｜材质必须有重量
- 皮肤有毛孔/纹理/瑕疵/不均匀色，不是瓷器；衣服有褶皱、旧感、洗痕、重量感；物件有使用痕迹。
- 禁止：瓷娃娃皮肤、无痕新衣、抛光金属感、每根发丝都反光、全画面锐利到像渲染。
- 风格化档转写：纸纹/笔触干湿/上色不匀/留白自然，禁止"数字喷绘滑溜感"。

### 规则2｜每张只放必要信息
- 每张定稿图/每段提示词：**2-3 个具体场景事实 + 1 个主动作 + 1 个次要线索 + 1 个主光源 + 1 个主要构图决定**。
- 禁止"把角色全部特征、全部装饰、全部氛围词同时堆进一条 prompt"——名词堆叠是 AI 油腻的最常见来源。
- 详尽的角色设定特征按需分层给：**身份/身材/脸型**优先，**服装细节**其次，**环境氛围**再次；放不下的留到下一组或转文字约束，不硬塞。

### 规则3｜光必须有来源
- 画面里每个可见光都要能指出实体来源：窗、灯、天光、水面反射、烛火、设备屏。
- 禁止：无来源轮廓光、皮肤整体发光、到处体积光/烟雾、为"电影感"硬加的发光粒子。
- 保留一个主光源方向与明暗关系（跟随 `CL`），暗部可以看不见细节。

### 规则4｜不完美是真实感来源
- 允许：面部瑕疵、轻微不对称、局部过曝/欠曝、背景不清晰、部分肢体出画或被挡、衣物起皱、眼神疲惫。
- 禁止：HDR 式全清晰、所有物体都干净发光、每处光影都"正确好看"。

### 规则5｜情绪不演给镜头
- 表情不完整、视线不必看镜头、人在做事件（走路/捡东西/发呆/转头）而不是站在展示台上。
- 禁止：证件照式对镜微笑、标准"看镜头 + 全脸受光"的摆拍脸。

## 3. 成像/质感基底（仅真人实景档，每批选一个）

写进 prompt 的质感基调一次只选一种，不要混搭：
- 35mm 发行拷贝：柔和过渡、低反差、细颗粒。
- 16mm 转电视：分辨率更软、颗粒粗、纪录片即时感。
- 早期数码电影机：暗部扎实、皮肤真实、轻微高光裁切。
- 长焦胶片压缩：人物有纵深压缩、背景柔化但不糊成奶。
- 手持纪录 35mm：微晃、跟拍真实、构图不完美。

## 4. 词级禁令（并入 NP / Avoid 使用）

可直接进 `NP` 负面词或 06 `Avoid` 的高频词（按档位取舍）：
- 通用：`CG render`、`3D model look`、`game key art`、`concept art`、`illustration smoothness`（风格化档慎用这条）、`glossy`、`HDR clarity`、`over-sharpened`、`plastic skin`、`porcelain face`、`airbrushed`、`perfect symmetry`、`artificial rim light`、`every surface glowing`、`teal-orange grade`、`commercial beauty lighting`。
- 空泛堆砌词（用可见事实替代，不要出现在 prompt 里）：`cinematic`、`beautiful`、`perfect`、`epic`、`highly detailed`、`rich detail`、`intricate`、`masterpiece`、`dreamy`。

## 5. 生成前自检（05 定稿图 / 06 提示词都过）

1. 是否属于风格化档却误用了实拍胶片/皮肤词？（绘本/2D 禁用 live-action 基底）
2. 是否一张图/一段塞了超过 3 个场景事实或多种氛围？（砍到必要）
3. 皮肤/服装/道具有没有"完美无痕"描写？（改写成有重量/有痕迹）
4. 光能否指出实体来源？有没有无来源轮廓光？
5. 人物是在做事件，还是站桩对镜头？
6. `NP`/`Avoid` 是否漏了本文件 §4 的高频词？
7. 空泛堆砌词（cinematic/perfect/rich detail 等）是否清空？

**一票否决**：成品像 CG 概念图、游戏立绘、AI 壁纸、过度磨皮、全画面发光、或"每处都完美" → 不回填直接重写，不进入下一步。

## 6. 与 roubaai-video-skill 既有体系的关系

- 本文件只加"材质真实感"这一层，不覆盖 05 的 `ST`/`CL`/`NP`（风格锁、色彩光影、防跑偏负面词仍各自生效）。
- 05 角色定稿图生成前：把 §4 禁令并入本次负面词，§2 规则写成可见事实加进 prompt。
- 06 提示词：把 §3 基底（真人档）或 §2 风格转写（风格化档）与 Must Keep/Avoid 合并输出；不新增多余参数。
- 用户没抱怨 AI 感、项目风格稳定时，本文件规则不必每条都显式输出，只把 §4 并入负面词即可；命中触发场景时再全量走 §5 自检。

## 7. 质感种子图锚定法（防 AI 感的最有效路径）

**现象**：直接靠文字约束（"不要塑料感 / 要有纹理 / 光来自窗户"）生成的图，防 AI 效果弱于"先产出一张质感已经对的种子图，再以它为参考扩图"。
**机制**：文字是负向约束——模型概率性理解、易漂移、易反向过冲（一说"别塑料"就加噪变脏）；参考图是像素级正向先验——质感/光影/材质方向直接从图继承。**图参照 > 文字约束**，这是生图模型注意力的基本事实。

**推荐流程（在 05 角色定稿图/四视图之前执行）**：

1. **先出 1 张质感种子图**：按 §2-§3 规则生成单张角色"入画在事件/环境里"的图（材质真实、光源有实体来源、反油腻），或接受用户从外部强反 AI 工作流（如 cinema-dna 类）产出的种子图。此时**不做四视图、不要多角度**，只求"这个人长什么样 + 质感基调对"。
2. **种子不达标不进下一步**：先用 §5 自检 + 一票否决筛种子；不达标就重出种子，**不要拿差种子硬扩四视图**（差种子扩四视图只会把假感复制四份）。
3. **以种子图为角色基准参考图**：把种子图作为该角色 05 的基准 `@图N`，再生成四视图 / 多角度 / 表情 / 服装变体。四视图从种子**继承长相与质感**，而不是每个角度各自发明一遍角色——后者正是"四视图像 AI 脸、互相不一致"的根源。
4. **只改视角/动作/服装，不改基底**：变体前先列"保留项"（脸型、发色、皮肤质感、服装原型、成像基底）；角度可以转，但材质基调、脸型结构、光的语言不得漂移。
5. **多个角色同流程**：每个核心角色都先有自己的种子图，再各自扩资产；不要用一条 prompt 同时发明多个角色。

**为什么这比纯文字好**：
- 种子图锚定 = 从"对的例子"长出来，一致且质感真；
- 纯文字出图 = 从"描述"猜出来，每次发明一遍人，容易滑回默认 AI 脸。
- 该流程与"05 参考图/上传参考"体系天然兼容：种子图就是该角色第一张基准参考图，后续 @图N 全部由它派生。
