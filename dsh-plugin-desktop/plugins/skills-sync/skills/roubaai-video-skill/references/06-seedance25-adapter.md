# Seedance 2.5 适配：30 秒大分镜提示词

> 本文件只在**用户选择 Seedance 2.5**时读取。
> Seedance 2.0 的 4-15 秒规则，走 `06-seedance2-adapter.md`。

---

## 0. 什么时候走本文件

| 输入 | 走哪条 |
|---|---|
| config `model` 含 `seedance-2.0`（如 `doubao-seedance-2.0-fast`）、config 默认、用户未声明 2.5、或用户说"按 2.0" | **保持现状**：`06-seedance2-adapter.md`（4-15s / C-A-B / 节奏档位闸门） |
| config `model` 含 `seedance-2.5`（按平台 2.5 模型名）或用户明确说"用 2.5 / 支持 30s 大分镜" | **本文件**：4-30s 大分镜（全局设定 + 时间戳分镜剧本） |

判定依据优先级：用户明确声明 > config `model` > 默认 2.0。判定结果放在代码框外第一行，如 `模型：Seedance 2.5（30s 大分镜）`。

---

## 1. Seedance 2.5 能力边界

| 能力 | 2.5 | 相对 2.0 |
|---|---|---|
| 单段时长 | **4-30 秒** | 15 → 30，翻倍 |
| 时间戳 | **原生支持秒级时间戳剧本** | 2.0 只建议软节奏，不写硬时间码 |
| 分辨率 | 480p / 720p / 1080p（无 4K） | 与 2.0 相同档位（2.0 另有 4K） |
| 比例 | 16:9 / 9:16 / 4:3 / 3:4 / 21:9 / 1:1 | 相同 |
| 参考图 | 单组仍 ≤ 9 张（Molyin 档位 1-9） | 相同上限 |
| 参考视频 / 音频 | 最多各 3 段 / 3 条 | 相同 |
| 负向指令 | "无字幕 / 无 BGM" 高概率生效 | 更稳 |
| 多语言 | 中英西印尼马来优先，覆盖泰阿葡越日韩 | 更广 |

2.5 的 30 秒大分镜是**一条提示词出整段**，不是靠拆多段拼——这是它与 2.0 最根本的差别。04 的多个连续镜头在 2.5 下可以并进一个 30 秒单元，用时间戳切片组织。

## 2. 30 秒大分镜标准结构

### 2.1 总结构（两段式）

```text
【全局场景设定】        ← 全片共享，放最前
  基础环境：
  视觉风格：
  镜头语言：
  人物造型：
  表演核心：
  禁止项：
【情绪与动作分镜】      ← 时间戳切片剧本
  [起-止] 切片N【阶段主题】：动作/表情/物理指令。潜台词：……
  ...（连续切片，可含转场指令）
```

官方验证的 30 秒骨架 = **全局设定 + 时间戳分镜**。两段都不可省：全局设定管"这 30 秒是什么世界"，时间戳切片管"每秒发生什么"。

### 2.2 时间戳切片公式

```text
[开始秒-结束秒] + [阶段主题] + [动作/表情/物理指令] + 可选[情感潜台词]
```

- **开始-结束秒**：写明确起止（`00:00-00:04`、`0-3s`）。2.5 能秒级执行。
- **阶段主题**：给切片起名（如「追问」「认命」），帮模型抓段落情绪基调。
- **动作/物理指令**：景别 + 构图 + 人物细节动作——本切片必须严格遵守的画面事实。
- **情感潜台词**：向模型解释动作背后的表达意图（如「她不是在痛诉，而是在等一个答案」）。写了它，表演细腻度明显提升。

### 2.3 转场公式（多镜头时）

```text
[转场类型指引] + 可选[基础约束要求] + [切镜逻辑要求]
```

- 在时间戳切片里点名转场方式，如 `00:11-00:18（动作甩镜转场）`、`00:19-00:24（遮罩转场）`。
- 常用：自然镜头切换 / 淡入淡出 / 叠化 / 白闪黑闪 / 遮罩转场（物体遮挡变黑后拉开）/ 相似物转场（圆月化酒碗）/ 动作转场（甩镜）/ 动态接力转场（换装）/ 拉近拉远转场（瞳孔套娃）/ 水墨转场。
- 可给候选让模型自选：「请从自然切换/遮罩/相似物转场中，根据本片风格选择最合适的一种」。
- 转场禁止项要用负向时序约束：如「水墨化效果只能在 25 秒之后出现，禁止提前」。

### 2.4 结构示例（可投喂骨架）

```text
【全局场景设定】
基础环境：深夜江边，背景有模糊的小船，寂寥送别场景，氛围安静克制。
视觉风格：电影感，浅景深，柔和自然光。
镜头语言：始终保持在女子近景特写，主观视角，轻微手持呼吸感，无快速剪辑。
人物造型：将 @图片1 中的 22 岁东亚女性、古典温婉脸、素白交领古装定义为 <她>，保留真实毛孔与肌肤纹理。
表演核心：克制细腻，重点呈现眼神流转、呼吸起伏、唇部微颤、喉头吞咽、眼泪自然滑落。
禁止项：禁止夸张哭腔，禁止快速剪辑，禁止大幅肢体动作，禁止多余台词或 BGM，禁止眼泪提前滴落。
【情绪与动作分镜（0-29 秒）】
00:00-00:03 切片1【追问】：<她> 直视镜头，眉心微蹙，嘴唇微启，轻声低语：「真的要走吗」。潜台词：不是在痛诉，是在等一个早已猜到答案的回答。
00:03-00:10 切片2【认命】：视线移开望空地，眼睑低垂，嘴角牵起短暂苦笑旋即落下，鼻翼轻收缩，克制地小声吸气。潜台词：强行把委屈咽回肚子。
...（后续切片按剧情推进）
```

## 3. 与 2.0 的差异对照（组织方式）

| 维度 | 2.0（现状，不变） | 2.5（本文件） |
|---|---|---|
| 单段时长 | 4-15s，超 15 拆段 | 4-30s，超 30 拆大分镜（按切片边界） |
| 正文组织 | C 导演轨（`镜头轨`）或 A 字段化 | **全局设定 + 时间戳切片剧本** |
| 时间控制 | 默认不写硬时间戳，软节奏 | **秒级时间戳是主控制**（`[起-止] + 主题 + 指令 + 潜台词`） |
| 镜头组织 | `N｜镜头功能标签｜镜头/焦点｜动作/台词｜光影/转接` | 切片即镜头，每切片写阶段主题 + 动作/表情 + 潜台词 |
| 转场 | 并入镜头轨 `光影/转接` | 显式转场公式，可点名转场类型 |
| 节奏档位映射 | 秒数 × 镜头密度表（4-6/7-9/10-12/13-15） | 30s 内切片数 × 切片长度（见 §5） |
| 台词闸门 | 语速 × 停顿 + 表演补偿，超 15s 拆连续单元 | 同一语速闸门，30s 内自然容纳更多台词；超 30 仍拆 |
| 字数闸门 | 1900 安全 / 2000 自律闸门（**非平台限制**：2.5 控制台 15000 字、API 侧无硬上限） | 保持 1900/2000；30s 官方示例约 700-1000 字，足够 |
| 参数 | model=2.0，4-15s | model=2.5，4-30s |

**为什么 30s 用时间戳而不是镜头轨**：2.5 官方验证的 30s 写法的核心是"指哪打哪"——秒级时间戳让模型知道第几秒做什么、第几秒切镜。2.0 的镜头轨默认不写硬时间码，照搬到 30s 会丢失时序控制。两者是**组织语言不同**，不是字段多少不同。

## 4. 从 04/05 继承（与 2.0 通用红线，全部保留）

以下规则两个模型通用，2.5 模式同样执行，不因"大分镜"放宽：

1. **素材锚定 ≤ 9 张图**：单组实际引用 `@图片N` 最多 9 张（人物/场景/道具/首帧/调度/SCV 全算）。30s 大分镜引用更多时先筛选、合并、转文字约束或拆到下一单元。
2. **人物锚定固定句式**：`将 @图片N 中的[身份/外观/服装]定义为 <角色名>`，后续切片用 `<角色名>` 指代；不裸写 asset-xxx / CH001 / SC001 内部 ID。
3. **台词不改写**：06 只保留原台词并做可执行性检查；中文语速 3-4（慢）/ 4-5（常）/ 5-6（快）字/秒，超 6 高风险；估算停顿（逗号 0.2s、句号 0.4s、省略号 0.6-1s）+ 表演补偿（0.5-1.5s）。30s 内放不下 → 按切片边界拆连续单元；必须改短 → 回 `03`。
4. **去管理话术**：纯净提示词不写"接下一大分镜 / 接分镜2 / 未启用 / 无则删除 / 不继承上一场"；衔接写可见动作或段末状态。`9:16 / 30秒 / 1080p / 模式` 放代码框外。
5. **BGM 归 07**：06 只生成环境声、对白原声、同步音效，不生成 BGM；2.5 的"无 BGM"负向指令高概率生效，可直接写进禁止项。
6. **编辑 / 延长指向 @视频**：编辑写 `严格编辑 @视频N`，延长写 `向后延长 @视频N` 或自然延长启动句；不写"参考 @视频N"。
7. **负向时序约束**：2.5 能压住"禁止提前"类时序禁止项（如"禁止眼泪提前滴落""水墨效果只能在 25s 后出现"）——该写就写，这是 2.5 才压得住的精度。
8. **素材编号一致性自检**：切片里出现的每个 `@图片/@视频/@音频` 编号必须在素材锚定或参考/连续性声明中定义，图号不混用。
9. **光影可执行**：写光源来源、主光方向、亮区暗区、脸部受光、色温反差；不写"电影级布光"空话。
10. **情绪拆微动作**：不写"悲伤 / 愤怒"，写眼神、眨眼、嘴部、呼吸、肩颈、手部的可见变化，禁止项写清不要假哭/夸张。

## 5. 节奏档位 → 30s 切片映射

2.5 大分镜继承 04 的 `节奏档位判定`，映射为 30s 内的**切片数 × 切片长度**：

| 节奏档位 | 30s 切片建议 | 说明 |
|---|---|---|
| 电影感中速 | 3-5 切片，每片 5-9s | 长镜头多，切片边界即情绪转折点 |
| 短视频中高密度 | 6-9 切片，每片 3-5s | 信息点多，切片密 |
| 高密度动作或强钩子 | 8-12 切片，每片 2-4s | 动作连打，切片即动作节拍 |
| 慢节奏但高信息 | 2-3 切片，每片 10-15s | 必须写清慢镜头功能，禁止无功能拖沓 |

- 切片数含转场点：每次切镜 = 一个切片边界。
- 30s 内 1-2 个切片必须命中慢节奏白名单并写清功能；否则补动作标点、道具信息、反应镜头。
- 04 未给节奏档位时，06 按平台、剧情功能、对白长度、动作密度自动补判。

## 6. 台词时长闸门（2.5 版本）

同一公式，上限改为 30s：

```text
台词基础时长 = 中文字数 ÷ 目标语速
停顿补偿 = 逗号/顿号 0.2s，句号/问号/叹号 0.4s，省略号/情绪停顿 0.6-1s
表演补偿 = 开口前/后反应、视线变化、动作承接，至少 0.5-1.5s
最低建议时长 = 基础 + 停顿 + 表演补偿
```

- 30s 内自然说完 → 直接可用。
- 超过 30s → 按台词自然停顿、问答回合或情绪转折拆成多个 30s 大分镜单元，前一单元 `段末状态` 承接下一单元第一帧。
- 必须改短台词 → 回 `03-dialogue-expert.md`；06 不得擅自删字。

## 7. 字数闸门（2.5 版本）

- 30s 大分镜信息密度高，但官方 30s 示例约 700-1000 字，**1900 安全线足够**。
- 仍执行 1900/2000 闸门（自律值，非平台限制）：≤1900 可交付；1901-2000 先压缩；>2000 先删低收益后缀、管理话术、重复限制和空泛形容词。镜头数不设限；超过 1900 字时，按切片边界拆成连续 30s 单元（每单元约 3 个分镜）。
- 若 12 个以上切片仍超 2000 字，按**切片边界**拆成连续 30s 单元（拆到 15s 以内属于降级，应优先避免），用上一单元段末状态承接。
- 禁止为压字数删除素材锚定、人物锚定、阶段主题、动作指令、潜台词、禁止项、段末状态。

## 9. 自检（2.5 大分镜）

输出前快速检查：

1. 是否已判定模型（2.0 走现状 / 2.5 走本文件），判定依据写在代码框外。
2. 是否用 `全局设定 + 时间戳分镜` 两段式；全局设定含基础环境/视觉风格/镜头语言/人物造型/表演核心/禁止项。
3. 每个切片是否写清 `[起-止秒] + 阶段主题 + 动作/表情指令`，潜台词按需。
4. 切片起止秒是否连续、不重叠、不超 30s 总长；最后一个切片到片尾。
5. 多镜头是否点名转场类型并写转场约束；负向时序禁止项（禁止提前）是否写清。
6. 素材 `@图片N` 是否 ≤9 张、人物锚定是否 `<角色名>`、图号是否不混用。
7. 台词是否保留原样并过语速闸门；超 30s 是否按切片边界拆单元。
8. 纯净提示词字数 ≤1900（1901-2000 压缩）；是否没有管理话术、参数、画幅混进代码框。
9. 是否没写"接下一大分镜 / 接分镜2"；衔接是否写成可见动作或段末状态。
10. 是否只生成环境声/对白/音效，BGM 归 07。

## 10. 与 2.0 共存的边界

- 本文件只改"2.5 模式的输出组织方式"，不触碰 `06-seedance2-adapter.md` / `06-core-format.md` / `06-continuity-assets.md` / `06-advanced-director.md` 的任何 2.0 规则。
- 用户从 2.5 切回 2.0，直接回到 2.0 路径，时长上限回落 15s、正文回到镜头轨；不要求 2.5 的 30s 分镜"降级续用"。
- 04 分镜在 2.5 模式下可输出 30s 大分镜前置单元（建议时长 4-30s、切片数与节奏档位映射）；在 2.0 模式下保持现状 4-15s。
