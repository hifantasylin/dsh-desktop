# 08 发布封面设计

## 1. 触发与输入

视频生成完成、粗剪完成或成片准备发布，需要主海报 / 平台尺寸封面时触发。

输入：
- 片名、副标题 / 关键文案
- 目标平台与尺寸：默认3:4，用户有需求另外设置。抖音 9:16 / 小红书 3:4 / B 站 16:9 / 快手 9:16 等（可多平台）
- 可用的定稿画面（视频帧、主视觉描述、关键道具/角色定稿图）
- 项目风格锁（ST/CL/NP，来自 05 资产库）

## 2. 产出

1. **3:4 主海报**（默认主视觉，单中心构图）。
2. **平台尺寸变体**：按目标平台输出 `9:16 / 1:1 / 16:9` 等；多集 name 带 EP 前缀。

## 3. 出图硬规则

1. **单中心 + 视线流量**：画面只有一个主体焦点，视线/构图引导向片名标题；不做分镜拼贴、不做游戏海报式堆叠。
2. **文字层级**：片名 > 副标题 > 角标；文字留白充分，不遮挡主体关键面部。
3. **ST/CL/NP 转译**：封面视觉继承 05 定稿的 ST/CL/NP，展开为自然语言；负面词含"多主体堆叠、文字溢出、面部变形、边缘裁切"。
4. 默认 `generate_image` 生成：3:4 主海报 `aspectRatio=3:4`，平台变体用对应 `aspectRatio`。
5. 封面 prompt 末尾同样追加 `05-handoff-output.md` 的"出图 Prompt 默认尾缀"。

## 4. 落盘（dsh）

```text
media_asset_save(category=cover, dir=13_封面, name=EPxx_主海报_3x4)
  → .assets/<项目名>/13_封面/EPxx_主海报_3x4.png
平台变体：name=EPxx_封面_9x16 / EPxx_封面_1x1（多集带 EP 前缀，单集可省略）
```

文件名与目录见 `references/deepseek-harness.md` §3.1 / `05-core-assets.md` 第三节。
