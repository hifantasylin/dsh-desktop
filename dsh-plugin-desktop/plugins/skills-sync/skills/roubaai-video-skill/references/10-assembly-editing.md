# 10 剪辑装配成片（JianYing 拼片）

## 1. 定位与边界

本模块负责把 06 生成的多段 AI 视频片段与 07 的 BGM/音效，按 04 分镜顺序装配成一条可发布的成片（时间线拼接 + 字幕 + 转场 + 音轨），导出 mp4。

剪辑实现走 **jianying-editor skill** 的 `JyProject` API（剪映草稿驱动），本文件只规定"拼什么、按什么顺序、加什么、加到哪"的编排规则。

### 本模块负责

- 多段视频片段按 04 分镜顺序排入时间线、无缝相接。
- 按 07 Cue Sheet 把 BGM/音效落到音轨进出点。
- 可选：对白字幕轨、04 明确要求的转场、片尾定格/黑场。
- 导出成片 mp4（Windows 无头导出 / 剪映手动导出）。

### 本模块不负责

- **不做内容手术**：AI 片段是对照剧本生成的定稿素材，无口误、无冗余需删。禁止套用"转录-删词-重排"类口播剪辑流程（那是 chengfeng 口播线，不适用于 AI 成片）。
- 不改写台词、不重排 04 分镜顺序、不替换/重新生成任何片段。
- 不生成画面、不做分镜动画（画面已烧在片段里）。
- 不负责封面（08 取成片帧）与声音设计（07 已完成）。
- 不为"片段能对上就多转场"而加转场；AI 片段之间叠加转场可能引入不可控画面。

## 2. 触发与输入

触发语（示例）：

- "视频片段都生成完了，帮我拼成一条片"
- "做剪辑装配 / 出成片"
- "把 06 的片段按分镜顺序排好加上 BGM 导出"

输入（先收集齐再动手，缺的向用户要或明确暂定）：

1. **06 片段清单**：每段文件名、镜序、时长、画幅、段末状态（在 `.assets/<项目名>/11_视频成片/EPxx/`，命名 `镜NN_简述.mp4`）。
2. **04 分镜顺序**：剧情顺序即时间线顺序；各接缝是否点名转场（`04-ai-video-storyboard.md` 的跨段衔接）。
3. **07 声音设计文档**（项目做过 07 时必读）：`<项目名>_声音设计.md`——07 的默认输出即含字幕呈现规则、字幕文本清单、BGM 素材指定、音效清单（见 `07-post-music-sound-design.md`「输出与落盘」默认部分）；BGM 音频在 `12_声音/BGM/`。
4. **项目画幅与名称**：从 `<项目名>_config.md` 读取；未定画幅先按平台节奏档案暂定并标注。

> 未做 07（无声音设计文档）：本阶段只拼画面 + 用户明确要的字幕（从剧本台词手动整理），不自动铺 BGM/音效，交接里注明"缺 07，建议补 07 后回来铺音"。

## 2.5 声音装配转换（07 设计 → 入轨规格，必做）

把 07 声音设计文档转成可入轨清单（红果子 EP01 已实测验证该过程）：

1. **实测时长**：对每段 06 片段 `ffprobe` 实测时长；按 04 顺序累计出每个 B 单元的绝对起点。**含替换镜/拆段的以实测为准，不用 07 预估时间码**（如 B07 拆"年轮过场 + 果堆重逢"两段时，07 按整段预估的绝对码会整体偏移）。
2. **字幕重投影**：把 07 文本清单的"单元内起止"换算成绝对秒；对白/旁白可同轨但时间不得重叠（重叠则错开，或分旁白/对白两条轨）；金句按 07 呈现规则用特殊样式（居中大字，颜色/字体对齐 config）落轨。
3. **BGM**：07 指定素材落 BGM 轨 0s；Cue Sheet 的静默点/分段音量是剪映手调项，写入交接，不强行自动化。
4. **音效**：本地有素材才落轨；07 清单标注"剪映音效库手动添加"的不 mock，输出搜索词清单给用户。
5. **落盘装配规格（推荐）**：`write` 到 `.assets/<项目名>/<项目名>_装配规格.md`——片段起点表、字幕表（文本/绝对码/类型/样式）、BGM/音效清单，供剪辑脚本消费与后续复核。

自检：字幕单轨无重叠；金句逐字；片段起点 = 实测累计；未沿用 07 预估绝对码。

## 3. 产出

1. **剪辑业务脚本**：`<项目根>/scripts/<项目名>_assemble.py`。按 jianying-editor skill 规则：**业务剪辑脚本一律放用户项目根目录，禁止写入 skill 库目录**；初始化头（`JyProject` 探测与 `sys.path`）以 jianying skill 的 SKILL.md 规范为准。
2. **剪映草稿**（JyProject 生成，位于剪映草稿根目录）。
3. **成片 mp4**：无头导出或用剪映打开草稿导出。

## 4. 装配规则（硬规则）

1. **顺序铁律**：时间线顺序 = 04 分镜顺序，不得重排、跳段、自创顺序。
2. **画幅铁律**：`JyProject` 初始必须按项目画幅显式设置分辨率，防止黑边：竖屏短剧 `9:16` → `width=1080, height=1920`；横屏 `16:9` → `1920x1080`。默认横屏，读 config 后覆盖。
3. **素材只引用不重生**：只引用 06 落盘文件路径（`11_视频成片/EPxx/`）；片段缺失、时长不符预期时先停下回报 06，不在本阶段补拍/重生成。
4. **时间线连续**：首段 `0s` 起，后续片段紧接前段尾（对齐 04 段末状态）；不留缺口、不叠画（除非 04 点名要叠化）。
5. **转场宁缺毋滥**：默认硬切；只在 04 明确要求转场的接缝加转场（素材用 jianying `asset_search` 检索，转场类型对齐 06-seedance25 §2.3 列表）；用户没提就不加。
6. **字幕**：按 §2.5 重投影后的清单进字幕轨。AI 片段常为无声（generateAudio=false），没有"音轨对白"可依——进点以 07 文本清单 + 实测片段起点为准；单轨不重叠；金句用特殊样式；不做口播式"句子分屏字幕"。
7. **音轨**：BGM/音效按 07 Cue Sheet 进出点落音频轨，注意淡入淡出；AI 片段自带环境声与对白，BGM 音量不得压台词（先对白、再环境声、BGM 最低优先级）。
8. **片尾**：按剧本需要留黑场或尾帧定格；无要求就随最后一段自然结束。
9. **保存与导出**：脚本末尾必须 `project.save()`；导出限制见 §5。

## 5. 平台与导出

- 无头导出 `scripts/auto_exporter.py <草稿名> out.mp4 --res <分辨率> --fps 30/60`：uiautomation 方式**仅 Windows + 剪映 v5.9 及以下**支持；实测前先确认剪映版本。
- macOS 或剪映版本更高：让用户在剪映里打开草稿手动导出（或引导剪映命令行导出）。
- 导出前如果剪映正在运行，提示退出重进草稿以刷新 UI。
- 剪映导出目标（建议）：`<项目根>/out/<项目名>_EPxx_成片_<时间戳>.mp4`；若需进入资产库由 05-core-assets 的 `11_视频成片/EPxx` 登记（名字带 `_成片_` 区分片段）。

## 6. 自检清单

输出前逐项过：

1. 时间线片段顺序与 04 完全一致，无重排。
2. 时间线连续无缺口、无意外叠画；画幅正确无黑边。
3. 转场只出现在 04 点名接缝，其余硬切。
4. 字幕（如启用）与音轨对白对齐。
5. BGM/音效进出点符合 07 Cue Sheet，未压对白；静默段无 BGM。
6. 素材引用全部存在（路径可读），无引用 06 未产出文件。
7. `project.save()` 已调用；草稿能打开；导出 mp4 可播放。
